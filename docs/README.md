# Evolução do sistema de scouting

Execute as etapas na ordem 1 a 8, uma por vez. Ao usar o Codex, solicite somente uma etapa por interação; peça primeiro leitura/auditoria, depois implementação e verificação daquela etapa. Atualize [STATUS-IMPLEMENTACAO.md](STATUS-IMPLEMENTACAO.md) após cada etapa. Não avance sem revisar decisões, alterações, testes e pendências da etapa atual.

A documentação orienta a adaptação do sistema existente, não uma reconstrução. Onde o comportamento ainda não foi confirmado, registre a investigação necessária.
